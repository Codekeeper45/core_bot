# Читалка чатов бота (локально, только чтение)

Простой веб-интерфейс, чтобы читать все диалоги бота в браузере. Только просмотр, никаких правок.

## Запуск

```bash
node viewer/server.js
# или
npm run viewer
```

Откроется на **http://localhost:3030** (порт можно сменить: `VIEWER_PORT=4000 npm run viewer`).

Берёт те же `MYSQL_*` из `.env`, что и бот, и читает таблицу `bot_chat_history`.

## Что показывает

- Слева — список чатов: имя (если собеседник есть в штате, иначе канал+id), канал, время
  последней активности, последняя реплика. Сверху — поиск.
- Справа — переписка: реплики клиента и бота, вызовы инструментов (серые чипы), «сводка памяти»
  сверху, если есть.

## Важно

- Сервер слушает **только 127.0.0.1** — из сети недоступен. **Не пробрасывай порт наружу.**
- Делает только `SELECT` — данные не меняет.
- У истории нет метки времени по каждому сообщению (так хранит бот) — показывается только время
  последней активности чата.
- Если не подключается к БД: скорее всего фаервол БД режет твой IP — запусти вьювер на сервере
  на 127.0.0.1 и открой через SSH-туннель (`ssh -L 3030:localhost:3030 …`).
